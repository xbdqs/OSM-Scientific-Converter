# SoftwareX peer-review documentation update

This main-branch update accompanies the revision of manuscript **SOFTX-D-26-01000**.

The validated software release remains **v0.4.1**. Peer review required stronger scientific grounding, related-tool context, terminology clarification, empirical scalability boundaries, profile-authoring documentation, standards-informed output-format framing, user value chains, and a validation-region overview figure. No review comment identified an algorithmic defect requiring a new release.

Accordingly, this update changes **documentation and publication materials only**. The validated `src/`, `tests/`, `config/`, built-in v0.4.1 profiles, and release binaries are not replaced. The tagged v0.4.1 release remains the permanent software version cited in the manuscript.

The revised manuscript distinguishes paper content from rebuttal content: reviewer-specific discussion remains in the point-by-point response and is not inserted into the scientific manuscript. Repository documentation records only enduring scientific scope, user guidance, limitations, provenance, and reproducibility information.
