# Public validation evidence

This directory contains minimized, path-redacted evidence for the validated v0.4.1 scientific core. Object-level reference sets, raw OSM/PBF data, GeoPackage/SQLite databases, local absolute paths, and the Chinese-interface GUI screenshots are intentionally excluded.

The public English GUI release must be rebuilt and revalidated from the repository before the Windows binary and final Figure 2 are published. Core performance evidence is retained because the GUI localization does not modify scanner, classifier, rules, exporter, or database schemas; see `docs/CORE_HASH_BOUNDARY.json`.
