# v0.4.2 Windows quick start

Use only a Windows ZIP after its packaged smoke report passes; retain the `_internal` directory beside the executable. The full five-stage workflow starts from `examples/sample_infrastructure.osm`. For roads, in Step 1 select `Quick roads (no scan)...`, choose `examples/round2_roads_small.osm`, a NEW GeoPackage destination and the packaged reviewed rule profile. The bounded map and limited audit are shown in Steps 4–5. Quick mode is **not** a complete tag inventory or geometry-quality audit.
