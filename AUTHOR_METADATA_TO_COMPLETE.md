# Required author metadata before public release

Replace the generic contributor placeholders before publishing the repository:

1. `CITATION.cff`: verified author names, ORCID identifiers, repository URL and release DOI when available;
2. `pyproject.toml`: verified package author name(s);
3. `LICENSE` and `Licence.txt`: copyright holder(s);
4. `README.md`: support email and repository/release links if added;
5. release metadata: GitHub release URL and Zenodo DOI when available.

Do not guess author order, affiliations, ORCID, funding, or corresponding-author information.
