# Manuscript and figures

The figure code and source data are under `figures/`. Figures 1, 3, 4, and 5 can be regenerated immediately with `python figures/code/run_all_ready_figures.py`.

Figure 2 must be generated from screenshots captured by the actual English GUI build. Run `tools/capture_publication_gui_english.bat` on Windows and then use `figures/code/figure_2_actual_english_gui.py`. Do not submit the earlier schematic or the Chinese-interface screenshots as evidence of the public English release.

The final manuscript and cover letter contain author, repository, DOI, and support-contact metadata and therefore are maintained outside the public code repository until those fields are verified.
